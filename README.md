## 中文说明

### 最新固件

请前往本仓库的 **Releases** 页面下载最新正式固件。

### 固件升级方法

1. 关闭 RLC3100。
2. 按住 **K4** 键并开机，进入 **USB UPDATE** 模式。
3. 使用 USB 数据线将 RLC3100 连接到电脑。
4. 等待电脑识别并显示 RLC3100 USB 磁盘。
5. 从本仓库的 **Releases** 页面下载对应的官方升级文件。
6. 将升级文件复制到 RLC3100 USB 磁盘。
7. 等待设备完成固件校验和升级。
8. 升级完成后重新启动设备。

### 注意事项

- 请仅使用本仓库正式发布的官方升级文件。
- 请勿修改升级文件的内容。
- 升级过程中请勿断开 USB。
- 升级过程中请勿关闭设备电源。
- 如果升级文件无效或不匹配，设备会拒绝升级。
- 请优先使用最新正式版本。

### 下载固件

请点击本页面右侧或上方的 **Releases**，进入固件发布页面。

## English

### Latest Firmware

Please visit the **Releases** section of this repository to download the latest official firmware.

### Firmware Update Instructions

1. Power off the RLC3100.
2. Hold the **K4** key while powering on the device to enter **USB UPDATE** mode.
3. Connect the RLC3100 to your computer using a USB data cable.
4. Wait for the RLC3100 USB drive to appear on the computer.
5. Download the official firmware update file from the **Releases** section of this repository.
6. Copy the firmware update file to the RLC3100 USB drive.
7. Wait for the device to verify and complete the firmware update.
8. Restart the device after the update is completed.

### Important Notes

- Use only official firmware files published in this repository.
- Do not modify the firmware update file.
- Do not disconnect the USB cable during the update.
- Do not power off the device during the update.
- Invalid or incompatible firmware files will be rejected by the device.
- Using the latest official release is recommended.

### Firmware Download

Please open the **Releases** section of this repository to download the latest firmware.
